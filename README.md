# Stewart River Iron-Removal System

EWB Challenge 2026 – Design Area 6.2 Drinking water quality and treatment – Port Stewart, Lama Lama Country.

## Where things are
- Each page is one file in `src/pages/` (for example `CostsPage.tsx`).
- All cost numbers are in `src/data/costs.ts`. Change a number there and every total updates by itself. Each number is marked there as SUPPLIER (a listed price), ATO (a tax-office rate) or TEAM (our allowance, not a quote).
- Rainfall data for Figure 2 is in `src/data/rainfall.ts`.
- The rainbow diagram (Figure 3) is drawn from `src/data/stakeholders.ts`.
- Every figure and its credit line is drawn by `src/components/Figure.tsx`.
- The reference list is in `src/pages/ReferencesPage.tsx`. Add a source there before you cite it in the text.

## Edit the text
On GitHub: open the file, click the pencil icon, change the words, then commit. The site rebuilds by itself in about 1–2 minutes.

Keep to APA 7th:
- Write an abbreviation in full once (the first time it appears on the site), then use the short form.
- Every in-text citation, for example (Todio, 2026), must match one entry in the reference list, and every entry in the list must be cited somewhere.
- Credit lines under figures and tables start with "From …", "Data from …" or "Created by …". They carry no "Note." label.

## Add or change images
Put images in `public/images/` using the file names in `public/images/README.txt`.
A figure whose image file is missing is hidden, so nothing broken shows on the page.
Every image needs a credit line (who made it, or where it came from) and, for a photo of people, their permission.
