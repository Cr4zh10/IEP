# Stewart River Iron-Removal System

EWB Challenge 2026 – Design Area 6.2 Water quality and treatment – Port Stewart, Lama Lama Country.

## Edit the text
Each page is one file in `src/pages/` (for example `CostsPage.tsx`, `TeamPage.tsx`).
On GitHub: open the file → click the pencil icon → edit the words between the tags → Commit changes.
The website rebuilds by itself in about 1–2 minutes.

## Add images
Put images in `public/images/` using the file names listed in `public/images/README.txt`.

## Team page
Edit `src/pages/TeamPage.tsx` to add names and contributions.
