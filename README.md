# Stewart River Iron-Removal System

EWB Challenge 2026 – Design Area 6.2 Drinking water quality and treatment – Port Stewart, Lama Lama Country.

## Where things are
- Each page is one file in `src/pages/` (for example `CostsPage.tsx`).
- All cost numbers are in `src/data/costs.ts`. Change a number there and the totals update by themselves.
- Rainfall data for Figure 2 is in `src/data/rainfall.ts`.
- `src/config.ts` has one switch, `SHOW_DRAFT_BADGES`. Set it to `false` when the team has checked the draft artefacts.

## Edit the text
On GitHub: open the file, click the pencil icon, change the words, then commit. The site rebuilds by itself in about 1–2 minutes.
Keep the APA 7th rules: write an abbreviation in full once (the first time it appears on the site), then use the short form.

## Add images
Put images in `public/images/` using the file names in `public/images/README.txt`.
Photos (`photo-home.jpg`, `photo-river.jpg`) only appear if the file exists. Always write who took the photo.
